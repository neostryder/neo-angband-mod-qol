The wave 6 entries use the c4d0bf92e local pack and Core source. Birth review and Attunement use public API 2.6.0 policies and content.

QOL-390 is verified against the c4d0bf92e lab build on 2026-11-16. On seed 390, fresh 1x and 4x characters contain 135 and 540 randomized artifacts, respectively, plus the same three fixed artifacts.
